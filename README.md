# جرين ترافيل Green Travel — موقع وكالة طيران

موقع ثابت (HTML/CSS/JS بدون أي اعتماديات) لوكالة سفر وطيران محلية ودولية، عربي بالكامل (RTL) ومتجاوب مع الجوال.

## الأقسام
- شريط علوي بمعلومات التواصل، وهيدر ثابت مع قائمة جوال
- واجهة رئيسية + **محرك بحث** بأربعة تبويبات: طيران (ذهاب/عودة، داخلي/دولي، درجة السفر، المسافرون، اقتراحات مطارات)، فنادق، باقات، تأشيرات
- شركاء الطيران (شريط متحرك)، الخدمات (8 خدمات)، أرقام متحركة
- الوجهات الأكثر طلباً (سلايدر) — الضغط على وجهة يعبّئ خانة "إلى"
- العروض مع تصفية (دولية/داخلية/باقات/عمرة)، قسم العمرة بثلاث فئات
- لماذا نحن، خطوات الحجز، آراء العملاء، الأسئلة الشائعة، الاشتراك بالنشرة، نموذج التواصل، الفوتر
- زر واتساب عائم، نافذة ملخص الطلب تُرسل الطلب جاهزاً إلى واتساب

## التخصيص السريع
1. **بيانات التواصل:** عدّل الكائن `CONFIG` أعلى `assets/js/main.js`: قائمة `numbers` (كل رقم للاتصال وواتساب) والبريد.
2. **اسم الشركة:** ابحث عن "جرين ترافيل" في `index.html`.
3. **العملة:** الأسعار مكتوبة بالريال (ر.س) في `index.html`.
4. **استقبال نموذج التواصل:** أضف `data-endpoint="https://formspree.io/f/xxxx"` إلى `<form id="contactForm">` (أو أي خادم يستقبل POST). بدونه يعرض النموذج رسالة نجاح فقط، وزر واتساب يعمل دائماً.
5. **SEO:** حدّث `canonical` و`og:*` وبيانات JSON-LD في `<head>` بعد ربط النطاق.

## التشغيل محلياً
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```
يمكن نشره كما هو على Netlify أو Vercel أو GitHub Pages.

الصور من Unsplash (ترخيص Unsplash يسمح بالاستخدام التجاري).

## البحث عن الرحلات
- قائمة المطارات في `assets/data/airports.json` (8,952 مطاراً لها رمز IATA في 236 دولة، من بيانات OurAirports المفتوحة؛ المطارات الرئيسية تظهر أولاً).
- شعارات شركات الطيران في `assets/img/airlines/<رمز الشركة>.webp`. البحث بالعربية أو الإنجليزية: اسم المدينة أو الدولة أو رمز المطار.
- بعد البحث تظهر صفحة نتائج بأسعار **تقديرية** تُحسب في المتصفح (المسافة، الدرجة، تاريخ السفر، عدد المسافرين) مع فلاتر وترتيب. زر "احجز الآن" يرسل تفاصيل الرحلة إلى واتساب ليؤكد الوكيل السعر النهائي.
- لعرض أسعار حقيقية مباشرة يلزم ربط الموقع بواجهة برمجية لشركة حجز (مثل Duffel أو Amadeus) عبر خادم صغير يحفظ مفتاح الواجهة.

## خيارا الحجز في نتائج البحث
- **احجز الآن:** نموذج يدخل فيه العميل أسماء المسافرين (كما في الجواز) وتاريخ الميلاد ورقم الجوال والبريد، ويحصل على رقم طلب (مثل GT-261122-1536). لاستقبال الطلبات مباشرة ضع رابط خدمة النماذج في `CONFIG.bookingEndpoint` داخل `assets/js/main.js`؛ وإن تُرك فارغاً يُرسل العميل الطلب الجاهز إلى واتساب بضغطة واحدة.
- **احجز عبر الوكيل:** يفتح ملخص الرحلة مع أزرار واتساب والاتصال على الأرقام الأربعة.

## اللغتان (العربية / English)
- زر **English / عربي** في الشريط العلوي يبدّل لغة الموقع بالكامل واتجاهه (من اليمين لليسار أو العكس)، ويتذكر اختيار الزائر.
- يمكن فتح الموقع بلغة محددة عبر `?lang=en` أو `?lang=ar`.
- ترجمة نصوص الصفحة في `assets/js/i18n-en.js` (المفتاح هو النص العربي كما في `index.html`)، ونصوص البرمجة عبر `T("عربي", "English")`.
- عند تعديل نص عربي في `index.html` حدّث مفتاحه في `i18n-en.js`.

## العملة
- جميع الأسعار بالدولار الأمريكي (USD). نقطة المغادرة الافتراضية في البحث هي شيكاغو أوهير (ORD).

## التصميم (2026)
- **الواجهة:** خريطة حيّة لمسارات الطيران من شيكاغو مرسومة بنقاط 8,952 مطاراً (`assets/js/experience.js`)، وصندوق البحث على شكل بطاقة صعود الطائرة.
- **الوجهات:** لوحة مغادرات مطار مع رموز تتقلب (split-flap) وساعة شيكاغو الحيّة.
- **الخدمات:** شبكة Bento بالصور، ثم أقسام العمرة، لماذا نحن، الخدمة الشخصية (بطاقات أفقية)، خطوات الحجز بمسار طيران، من نحن، القيم، الأسئلة، التواصل.
- الألوان مأخوذة من شعار Green Travel مع لون كهرماني لإشارات المدرج.

## بوابة الشركاء (B2B) — `b2b.html` (نسخة تجريبية)
- تسجيل دخول تجريبي: `demo@partner.com` / `demo1234` (الحسابات في `ACCOUNTS` داخل `assets/js/b2b.js`).
- حساب جرين ترافيل التجريبي: `admin@greentravel.us` / `admin1234` — يرى لوحة **إعدادات التسعير** لاختيار نظام كل شريك: **سعر ثابت** أو **نسبة مئوية** أو **ثابت + نسبة**، وتحديد المبالغ.
- **التسعير** (`DEFAULT_PRICING` في `assets/js/b2b.js`، ويمكن تخصيصه لكل شريك):
  - تكلفتنا = سعر الموقع ÷ (1 + هامش الموقع `publicMarkup`، افتراضياً 8%)
  - نظام «ثابت + نسبة»: رسم الشريك = $20 ثابت إذا كانت التكلفة أقل من $1,000، و2% إذا كانت $1,000 فأكثر (لا قفزة عند الحد)
  - نظام «سعر ثابت»: نفس الرسم (افتراضياً $20) على كل تذكرة
  - نظام «نسبة مئوية»: نسبة ثابتة (افتراضياً 2%) من سعر كل تذكرة
  - سعر الشريك = التكلفة + الرسم، ويبقى دائماً أقل من سعر الموقع.
- الشريك يحدد بيانات وكالته وشعاره وهامش ربحه، وينشئ عروض أسعار باسمه (طباعة/PDF، واتساب، بريد)، ويطلب إصدار التذكرة من جرين ترافيل.
- ⚠️ البيانات تُحفظ في متصفح الشريك فقط وكلمة المرور مكتوبة في الكود؛ للاستخدام الفعلي يجب نقل الدخول والبيانات إلى خادم آمن (مثل Supabase Auth مع صلاحيات لكل شريك).

## المكتب الخلفي والمحاسبة — `office.html` (نسخة تجريبية)
نظام واحد يربط الموقع وبوابة الشركاء والمكتب الخلفي (`assets/js/store.js`):
- **حجز من الموقع** («احجز الآن») ← يظهر فوراً في المكتب كحجز جديد (المصدر: الموقع).
- **طلب إصدار من وكيل B2B** ← يظهر كحجز جديد (المصدر: شريك B2B) مع تكلفتنا وسعر الوكيل.
- الموظف يؤكد الحجز ويُدخل رقم الحجز PNR وأرقام التذاكر ← الوكيل يرى الحالة والتذكرة ورصيده في بوابته.

**المحاسبة:** مدفوعات العملاء (بطاقة/نقداً/تحويل/Zelle/شيك)، المدفوع للموردين وشركات الطيران، أرصدة وكلاء B2B وحد الائتمان،
كشف حساب لكل وكيل مع الرصيد الجاري، فواتير قابلة للطباعة، المصروفات، وقائمة الأرباح والخسائر (حسب الفترة والمصدر وشركة الطيران والوجهة) مع تصدير CSV.

**الصلاحيات:**
| الدور | يرى |
|---|---|
| مدير `admin@greentravel.us` / `admin1234` | كل شيء: المصروفات، التقارير المالية، الإعدادات، تسعير الوكلاء |
| وكيل سفر `agent@greentravel.us` / `agent1234` | لوحة التحكم، الحجوزات، المدفوعات، وكلاء B2B |
| شريك B2B | بوابة `b2b.html`: حجوزاته وتذاكره ورصيده فقط |

> ⚠️ تجريبي: البيانات محفوظة في متصفح واحد (localStorage) وكلمات المرور ظاهرة في الكود. للاستخدام الفعلي يُنقل النظام إلى قاعدة بيانات (مثل Supabase) بنفس الحقول مع تسجيل دخول آمن وصلاحيات على مستوى الصفوف.
